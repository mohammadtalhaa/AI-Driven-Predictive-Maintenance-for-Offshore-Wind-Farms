# 🌊 AI-Driven Predictive Maintenance for Offshore Wind Farms

https://mohammadtalhaa.github.io/AI-Driven-Predictive-Maintenance-for-Offshore-Wind-Farms/
This project demonstrates an end-to-end Machine Learning pipeline for predicting the **Remaining Useful Life (RUL)** of offshore wind turbine components using synthetic sensor data. 

**Why this project?** 
Norway is a global leader in offshore renewable energy. This project aligns with the country's strategic focus on sustainable AI and smart infrastructure, showcasing my ability to build, deploy, and serve ML models for real-world engineering challenges.

## 🚀 Live Demo
https://mohammadtalhaa.github.io/AI-Driven-Predictive-Maintenance-for-Offshore-Wind-Farms/
## 🧠 Model Architecture
- **Input**: 10 timesteps of 3 sensor readings (Vibration, Temperature, RPM) → Flattened to 30 features.
- **Layers**: Dense (64) → Dropout → Dense (32) → Dense (1).
- **Framework**: TensorFlow / Keras, converted to TensorFlow.js for browser inference.

## 📂 Repository Structure
- `train.py` - Script to generate synthetic data, train the model, and export it for the web.
- `index.html` - Single-page web application with embedded CSS/JS.
- `web_model/` - Contains `model.json` and `model.weights.bin` (generated by `train.py`).

## 🔧 How to Reproduce (Run Locally)
1. Clone this repository.
2. Install dependencies: `pip install numpy pandas scikit-learn tensorflow tensorflowjs`
3. Run `python train.py` to generate the `web_model` folder.
4. Push the repository to GitHub and enable Pages.

## 📊 Sample Data Format
The web app expects a CSV file with **3 columns**: `vibration`, `temperature`, `rpm`, and at least 10 rows. Use the "Download Sample CSV" button in the web app to test immediately.
